# Sociology Learning Lab — Bilingual GitHub Pages Resource

## Files
- `index.html` — language-first entry screen and application shell
- `styles.css` — responsive styling
- `app.js` — bilingual navigation, course views, progress tracking and interactions
- `data.js` — original English source course dataset (60 lecture records, quizzes, cases and simulations)

## Publish
Upload all files to the root of the existing GitHub repository and enable GitHub Pages from `main` / root.

## Important content note
The language gate, course overview, unit structure, lecture titles, assignments, learning outcomes and glossary are presented in the selected language. Some deeper interaction content (notably case-study scenario text, quiz questions and parts of thinker-simulation feedback) still uses English source wording in the Marathi view and requires a final translation/editing pass before describing the site as fully bilingual. The Marathi lecture objective/activity descriptions are concise learning-focus summaries rather than literal translations of every English record.

Progress is stored locally in the visitor’s browser. No student responses are transmitted to a server.
