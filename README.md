# Sociology Learning Lab – M.A. Sociology

A GitHub Pages-ready interactive learning resource for the M.A. Sociology course **Sociological Theory**.

## Learning features
- Full 60-lecture plan across four syllabus units
- Lecture-wise objectives, Bloom's Taxonomy levels and in-class activities
- Seven thinker simulations: A.R. Radcliffe-Brown, Talcott Parsons, Michel Foucault, Randall Collins, G.H. Mead, Herbert Blumer and Alfred Schutz
- Four applied case challenges
- Four unit quizzes (20 MCQs total) with immediate explanations
- Four unit assignments with suggested evaluation rubric
- CLO-to-lecture mapping and searchable glossary
- English interface with a Marathi language toggle
- Local lecture progress and quiz score tracking
- Responsive layout and print-friendly styles

## Files
- `index.html` – application structure
- `styles.css` – responsive interface
- `data.js` – course, lectures, cases, simulations, quizzes and glossary
- `app.js` – interaction logic, language toggle and progress tracking
- `.nojekyll` – GitHub Pages helper

## Run locally
Extract the files into one folder and open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Create a public repository, for example `sociology-learning-lab`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish and display the public URL.

## Data and privacy
- Lecture completion and quiz scores are stored in local browser storage on the device used.
- Case reflections and simulation responses are not transmitted to a server.
- There is no login, database or external API requirement.
- Google Fonts load when internet access is available; fallback fonts are provided.
